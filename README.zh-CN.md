# kits

[English — 主版本](README.md)

用于收集 Windows 工具软件清单的 Scoop bucket。

软件清单位于 `bucket/`，描述软件包并提供对应的发布下载地址、校验值和软件包要求。

## 软件清单

| 软件 | 简介 | 文档 |
| --- | --- | --- |
| rsc | 用 Rust 编写、兼容 Scoop 的 Windows 包管理器 | [rsc 中文 README](https://github.com/yhwwwwww/rsc/blob/main/README.zh-CN.md) |

各软件的安装与升级说明放在对应项目文档中，可通过上面的链接查看。
